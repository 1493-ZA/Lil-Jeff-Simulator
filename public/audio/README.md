These are original fictional character voices. Every line in `lines.json` is
generated by `scripts/generate-voices.py` with the open Kokoro-82M model
(Apache-2.0, see KOKORO-NOTICE.txt). Each crew member uses an original blend of
stock Kokoro voice styles plus a fixed pitch offset, so no artist or real
person's voice is sampled, imitated or cloned. Raps are fitted to the beat grid
(street cyphers: one bar per two notes at 92 BPM; studio: three lines per turn)
and double-tracked; dialogue gets light compression and room tone.

Regenerate: `pip install kokoro-onnx soundfile numpy`, download
`kokoro-v1.0.int8.onnx` and `voices-v1.0.bin` from the kokoro-onnx releases,
then run `KOKORO_MODEL=… KOKORO_VOICES=… python3 scripts/generate-voices.py`
(requires FFmpeg with rubberband). Runtime playback uses the bundled Ogg files;
no speech API, account or remote service is required.

Original percussion samples in drums/ are generated by scripts/generate-drums.py
with Python and NumPy; all six WAV files are bundled for runtime playback. No
external drum libraries or artist recordings are used. The mixer retains a
procedural fallback while these local samples load.
